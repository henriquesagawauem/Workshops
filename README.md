## 📌 Sobre o Repositório

Este repositório foi criado com o objetivo de centralizar, organizar e documentar todos os **workshops, minicursos, palestras práticas e eventos acadêmicos** que participei durante a minha graduação em Engenharia de Software na **Universidade Estadual de Maringá (UEM)**.

Aqui você encontrará códigos-fonte, anotações de aulas, scripts de testes e insights práticos de diversas áreas da tecnologia. O repositório serve tanto como um portfólio pessoal quanto como uma fonte de consulta rápida para o futuro.

---

## 📂 Estrutura do Repositório

A organização dos arquivos segue uma estrutura dividida por temas ou eventos, facilitando a navegação:

```text
├── 📁 Análise de Dados/          # Códigos, datasets e anotações sobre Data Science
│   ├── 📓 dia01_workshop_pandas.ipynb
│   └── 📝 Anotações_Aula_01.md
├── 📁 Docker/                    # Como buildar e rodar containers Docker
├── 📁 [Nome_Do_Futuro_Workshop]/ # Espaço para os próximos eventos
└── 📄 README.md                  # Documentação principal do repositório

```
